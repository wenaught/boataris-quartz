## Мешки и сумки

Вместимость мешков и рюкзака [[3. Атрибуты#Модификаторы Силы|зависит от СИЛ]] персонажа.

| Контейнер                            | Нагрузка | Вместимость |
| ------------------------------------ | -------- | ----------- |
| Рюкзак                               | 1        | 13–19       |
| Мешок                                |          |             |
| &ensp;Большой                        | 1        | 13–19       |
| &ensp;Маленький                      | 1        | 6–8         |

**Большой мешок** необходимо нести в двух руках, и он вмещает столько же, сколько рюкзак персонажа; **маленький** можно нести в одной руке, и он вмещает вдвое меньше рюкзака.

## Для жидкостей

| Контейнер                      | Нагрузка | Вместимость |
| ------------------------------ | -------- | ----------- |
| Бурдюк                         |          |             |
| &ensp;Большой                  | 1        | Галлон      |
| &ensp;Маленький                | 1        | 2 кварты    |
| Бутыль, глиняная               | 1        | Галлон      |
| Ведро                          | 2        | 5 галлонов  |
| Флакон, стеклянный             | †        | Унция       |
| Фляга, стальная или стеклянная | 1        | Пинта       |

**Флаконы** используются для чернил и святой воды.
**Фляги** используются для фонарного масла и крепких напитков.
